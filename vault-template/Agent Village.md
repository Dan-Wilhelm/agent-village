# Agent Village

Knowledge of the agents in my village. Settings and playbooks only — never copies of work data.

- `Shared/About me.md` — what every agent should know about me
- `Companies/<Company>/<Company>.md` — one note per work environment
- `Companies/<Company>/Teams/<Team>/<Team>.md` — teams (a lead is optional)
- `Companies/<Company>/Agents/<Role>/` — created by the agent wizard in the village
